Generic request

Entry accepts 2 through 8 ASCII letters, digits or hyphens. Errors, Back, cancel and rerender preserve this draft and its option. New request clears both fields. Approve creates one record per draft. Re-entry and edit-resubmit update that record, never duplicate it. Cancel never changes records. Each fresh page starts with no records; this fixture has no persistent or server state.
