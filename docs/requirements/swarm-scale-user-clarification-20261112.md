# 사용자 최신 스웜 요구사항 정정 — 2026-11-12

이 문서는 조율자가 사용자 최신 메시지를 기존 개발 작업에 전달하기 위해 기록한 요구사항입니다. 기존 실행 증거를 바꾸지 않으며, 구현 완료나 개발 세션의 수신 확인을 의미하지 않습니다.

## 최종 구분

- **제품 개발**: 웹 ChatGPT **Pro**를 사용하고, 개발의 서브에이전트 세션은 **xhigh**를 활용한다. 사용자의 Codex 쿼터는 사용하지 않는다.
- **완성된 스킬의 실행 사용자**: DeepSeek, Luna, Haiku 같은 상대적으로 작고 저렴한 모델로 **수십~수백 개의 독립 persona 세션**을 한 프로젝트에서 운영할 수 있어야 한다. 특정 모델 이름은 사용자 예시이며 현재 연결·비용·지원 여부가 확인됐다는 뜻이 아니다.
- 웹 개발·연결 검증의 Pro/high/xhigh 선택과 출시 스킬의 저비용 persona worker 모델을 혼동하지 않는다. 'high/xhigh는 관리 전용'이라는 이전 조율 해석은 철회한다.

## 사용자 원문

> 상대적으로 작고 낮은 모델들로 돌리는 거란 말이야. 딥시크나 루나, 하이쿠 같은 모델들이 페르소나 수십 수백개 들고 따로 스웜.

> 아니 high xhigh는 웹에는 그거밖에 없으니까 임마. 사람이 그 스킬 쓰려면 작고 저렴한 모델 수십세션 정도가 타겟이겠지

> 니가 개발할 때는 … 웹PRO 써야지 그 서브 에이전트 세션 느낌으로 xhigh 쓰고

마지막 인용의 생략 부호는 조율자에게 전달된 사용자 발췌 그대로이며 원문 전체를 복원한 것이 아니다.

## 설계·검증 수용 기준

1. 저장된 다양한 persona를 각각 별도 모델 컨텍스트에서 실제 사용자처럼 행동시킨다. 단순 fixture, 한 모델의 일괄 역할극, 동시 함수 호출만으로 수십~수백 사용자 세션을 실행했다고 주장하지 않는다.
2. 공급자 중립의 실행 호스트 계약을 유지하고 실제 이용 가능한 모델·인증·요금/구독 한도를 확인한다. 미연동 공급자는 지원 완료로 표시하지 않는다.
3. persona 총수와 동시에 실행하는 세션 수를 분리한다. 큐, 동시성·예산 제한, 중단/재개, 중복 실행 방지, 불확실한 부작용 처리, 개별 증거 및 통합 결과를 관리한다.
4. 연결 증명인 두 persona 진단과 수십~수백 운영 능력, 실제 UX 결함 발견 효과를 분리한다. 단계적 실제 확장 시험에서 모델 호출·도구 실행·성공/실패·비용 또는 사용량·시간·자원을 실측한다. 모의 부하 시험은 실제 모델 시험과 별도 표기한다.
5. 일반 사용자는 대상·목표를 주면 사용할 수 있어야 한다. JSON, lease, 내부 큐 조작을 사용자에게 떠넘기지 않는다. 기존 공개 조사·PRD·영속 persona Library와 연결하며 합성 가설과 관측 근거를 구분한다.
6. 승인 없는 과금, Codex 쿼터, 개인 Chrome/사용 중인 화면 조작, 토큰 추출, 권한 확대 및 거절 우회를 금지한다. 디스크 여유가 약 21GiB로 보고되었으므로 대형 복제/다운로드/중복 산출을 최소화하고 기존 파일을 임의 삭제하지 않는다.

## 현재 전달 상태

조율자의 기존 소유 Aside 페이지 세션 복구 조회가 자동검토에서 거절되어, UI를 통한 최신 지시 전달은 중단됐다. 이 문서는 별도 승인된 레포 파일로 저장한 독립 handoff다. 현재 개발 세션이 실제 읽고 반영했는지는 별도로 확인해야 한다. 기존 진행 중 구현·검증·정상 push를 방해하거나 두 persona 증거를 삭제하지 않는다.
