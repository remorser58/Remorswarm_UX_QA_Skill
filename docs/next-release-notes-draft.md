# Draft: next release notes

Unreleased. This draft covers #40–#51, which are on `main` and are not in the published [v1.2.0 ZIP](https://github.com/remorser58/Remorswarm_UX_QA_Skill/releases/tag/v1.2.0).

## What users will notice

- **Read QA reports with clearer evidence boundaries.** Duplicate observations count once, not as independent evidence ([#40](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/40)). Ergonomics reports distinguish devices configured in profiles from devices actually exercised in runs ([#44](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/44)). Older reports with the exact previous duplicate wording can reopen without rewriting results when their companion JSON still matches; this compatibility exception does not accept edits or a missing JSON companion ([#45](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/45)).
- **Know what the checks do and don't verify.** Keyboard focus crops suppress animation, so compare the same action under both motion preferences without suppression to verify reduced motion ([#41](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/41)). RF-01 reports a static check at 320 CSS pixels, not a live zoom test ([#42](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/42)). CG-02 applies a 50 ms tolerance only to the duration comparison, not as a WCAG exception ([#46](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/46)). SM-04 needs a usable captured field; without one, no finding does not mean a pass ([#50](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/50)).
- **Get more actionable CLI and validation guidance.** An unregistered or wrong-kind Figma readback artifact reference now asks for a registered `figma_readback` artifact ID without echoing the rejected input ([#43](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/43)). Benchmark help distinguishes confirmatory results from descriptive results and tests that did not run ([#47](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/47)). Android snapshot examples show the required effective device density, and `ref` can open the supported surfaces table directly ([#48](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/48), [#49](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/49)).
- **Try ergonomics offline from the ZIP.** The bundled [synthetic icon-toggle example](../skills/remorsearch-ux-qa/examples/ergonomics/README.md) walks through bundled PNGs and run records, generating a report and scoring two seeded findings. No browser capture, real product or real user data is involved ([#51](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/51)).
- **Choose one ergonomics profile before capture.** The guide shows how to save a single profile that matches the planned device and orientation ([#53](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/53)).

## Compatibility: previously recorded ergonomics runs

[#42](https://github.com/remorser58/Remorswarm_UX_QA_Skill/pull/42) changed RF-01 wording in a file included in the evaluator's model-revision digest. That changes `model_revision_sha256` even though the thresholds and model ID did not change. The default evaluator rejects a profile-bound run with `recorded profile binding model_revision_mismatch` if its recorded model revision differs.

To reopen the original evaluation, use the exact evaluator build that matches the run's recorded model ID and `model_revision_sha256`, with the original profile and device configuration. A matching version label or model ID alone is not enough. For a new verified result on the newer evaluator, record a new run. `--analytical-rescore` is a separate analytical comparison, not a way to restore the original run's verified binding. Do not edit the recorded digest.
